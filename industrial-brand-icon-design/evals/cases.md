# Industrial Brand Icon Design — Evaluation Router

这些测试验证 Skill 是否真正改变设计决策、生成指令和最终视觉结果，而不是只复述规则。

## 三层验收

每个案例同时检查：

1. **决策层**：主体、动作、认知来源、候选比较与系列关系是否正确；
2. **指令层**：生成指令是否只包含当前任务相关规则，且没有互相冲突的要求；
3. **成图层**：实际图像是否直观、统一、简洁、无变形，双版本是否保持相同结构。

除非案例明确只测试决策，否则三层任一失败，整个案例失败。文字中声明“已评分”或“已统一”不能代替成图验收。

## 测试路由

- 历史能力与回归保护：读取 [regression-cases.md](regression-cases.md)，执行 Case 1–14。
- 近期真实失败与新增能力：读取 [recent-failure-cases.md](recent-failure-cases.md)，执行 Case 15–24。
- 沿用用户认可的诊断六图风格：同时读取 [诊断六图验收参考](../references/diagnostic-six-icon-acceptance.md)。

## 发布门槛

- Case 1–14 全部保持通过；
- Case 15–24 全部通过；
- 不允许为了通过新增测试而降低旧案例的语义、风格或输出标准；
- 透明 PNG 必须验证真实 alpha 通道，不能用棋盘格、白底或合成预览冒充；
- 没有实际执行成图测试时，只能报告“规则与结构验证通过”，不得声称视觉生成已经通过。
