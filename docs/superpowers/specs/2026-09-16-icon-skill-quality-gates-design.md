# 工业功能图标 Skill 质量门禁升级设计

## 目标

将现有“原则型”图标 Skill 升级为可执行的质量门禁系统，优先解决三个反复出现的问题：语义不直观、整组粗细/重心/构造不统一、生成前缺少真实有效的内部评分与打回。

## 用户体验

- 用户正常调用时不展示内部评分过程；评审合格后直接生成。
- 未达门槛的方案在内部静默打回，不展示失败版本。
- 连续三轮语义重构仍无法合格时，只询问一个关键语义选择，不交付伪合格结果。
- 默认继续输出两张同结构图：白色透明 PNG 与白底黑标。

## 执行架构

1. 识别任务类型并加载最少必要参考文件。
2. 拆解功能语义，为每项比较 2–3 个候选表达。
3. 通过语义门禁后进行整组视觉规划。
4. 通过系列门禁后才生成图像。
5. 对实际成图进行逐项复检；失败时返回对应阶段。
6. 验证双版本结构一致与透明 PNG 的真实 alpha 通道后交付。

## 生成前评分

- 语义直观度：40 分，最低 34 分。
- 系列一致性：35 分，最低 29 分。
- 简洁一体化：25 分，最低 21 分。
- 总分最低 88 分。
- 任何硬性否决项优先于总分。

评分必须关联可观察证据，不能仅声明“已统一”或“已通过”。不看标题时，图标应能传达核心对象、动作或大致方向；标题可以补足抽象功能的精确含义。

## 硬性否决

- 核心对象或动作无法大致识别。
- 相近功能无法区分。
- 用相同外框更换内部小符号制造假统一。
- 出现多个竞争视觉中心。
- 同组无理由混用纯线、重实心与剪影。
- 明显过长、过窄、过黑、过空或重心漂移。
- 依赖微小文字、颗粒或细线表达关键语义。
- 为做方而拉伸或压扁真实对象。
- 语义错误仅靠线粗或装饰修补。
- 用户明确锁定的结构被无授权重画。

## 抽象功能

将 Smart、Quick、Complete、Fast、Stable、Responsive、Carry Less、Water、Dust、Oil Resistant 等词先改写为可观察行为。按“直接对象 → 动作 → 状态 → 结果 → 公共隐喻”的顺序选择表达；每枚最多允许一次认知跳转。

## 局部修改

每枚图标分为硬锁定、视觉锚点或重新设计三种状态。记录主体、动作、主轮廓、辅助语义、线面关系、视觉盒/重心、关键内部结构七项指纹。整体复核不等于整体重画；未点名成员只有在确有系列问题时才进行最小必要微调。

## 评分边界

- “一个主体 + 0–1 辅助语义”是默认压缩方向，不机械限制已形成单一视觉中心的紧密组合。
- 24/32px 用于适配检查；必要时制作小尺寸简化版，不以此随意破坏已认可母版。
- 默认线面结合；用户明确要求或参考图需要时，允许纯线作为单次覆盖。
- 用户指定 5px 等数值时按当次硬参数执行；否则以光学一致为主。

- `references/style-guide.md`：视觉构造与系列参数。

- `references/reference-learning.md`：参考学习与规则生命周期。

- `evals/regression-cases.md`：原 Case 1–14。
- `evals/recent-failure-cases.md`：新增 Case 15–24。

## 验收

- 原 Case 1–14 不回退。
- 新 Case 15–24 覆盖扫描层级、性能词、DPF 五异常、硬件八图、评分真实性、局部锁定、13 图压力、The Noun Project 参考和纯线临时覆盖。
- 测试同时检查决策层、生成指令层和成图层，不接受只在文字中复述规则。
- 透明版本必须验证真实 alpha，不能用棋盘格或白底冒充。
